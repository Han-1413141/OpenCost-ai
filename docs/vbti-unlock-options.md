# VBTI 角色解锁候选方案

以下是供选择的方案，尚未替换现有个人图鉴解锁规则。当前主要角色已经按数值倾向排序；成就与主要角色分别展示。

## 方案一：工作倾向解锁角色，成就解锁装饰（建议）

每天先按现有倾向分判断主要角色与接近角色。同一角色在最近 30 天的至少 7 个有效记录日成为主要或接近角色时收入图鉴。当天多次上传只取最新记录。未知分母不算有效观察，不用增加 Token 消耗提高分数。

用户在积累期就能看到“本次倾向”，永久收藏则等待足够日期。成就提供边框、徽章或角色背景，模型和 Harness 标签挂在角色旁边。这样，工作方式决定角色，持续记录决定收藏，花费不会直接买到称号。

“至少 7 天”是待选择的产品门槛，实施前还需确定：只有主要角色计数，还是接近角色也计数。建议保留接近角色，允许真实的混合工作方式。

## 方案二：主类型随记录变化，全部角色按探索进度收藏

本次类型始终按数值排序。一个角色累计出现于 3、7、14 个不同日期时获得见习、熟练、常驻三个收藏等级。优点是进度更明显；缺点是图鉴状态更多，页面需要控制信息量。

## 方案三：角色只展示倾向，收藏全部放到成就

角色没有永久解锁，展示最近窗口最符合记录的类型；图鉴收藏改为记录天数、跨工具使用、稳定工作特点等成就。优点是含义最直接；缺点是角色收集动力较弱。

## 三种方案共同遵守的规则

- 当前类型、历史收藏、日常成就分别显示，避免用户把历史角色当成当前结论。
- 常用模型和 Harness 来自真实型号记录；至少 7 个不同日期才判断常用，不读取私人别名。
- 保留已有收藏，不因算法改版删除；新规则记录版本与生效时间。
- 公开图鉴的“100 个账号后揭晓”只是社区名称与条件的公开门槛，不替代个人解锁条件。
- 缺失记录标为缺失，不计失败或零分；不同日期去重，不奖励重复上传或额外消耗。

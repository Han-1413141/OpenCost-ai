# 固定任务条件内的来源等权对照

实现日期：2026-10-15。内部数值协议 `source-balance-internal-1`，公开协议 `source-balance-1`。对应清单 S-07 的来源均衡部分。

这项分析回答：如果每个任务条件中各已知关联来源组占相同权重，单位验收费用相对按任务量汇总会变化多少。它帮助用户判断当前结果对上传来源构成的依赖，不改变模型排名，也不重新选择 Harness。少数来源的结果影响大，不等于它们作弊。

## 计算对象与算法

使用来源留出评价侧已有的数值矩阵。模型、版本、每条件 Harness 完整配置、价格证据口径、任务条件和权重 q 均已冻结。每个组条件只有已结束独立根目标数 N、验收数 A、归属支出 C；失败目标费用保留。已知关联组由持有人及已确认来源关系形成，不是独立真人。

对模型 m 的条件 s，G_ms 只包含实际有该条件观测的组。分别计算：

```text
按任务量：U_s = Σg C_gs / Σg N_gs；V_s = Σg A_gs / Σg N_gs
来源等权：U'_s = [Σg(C_gs/N_gs)] / |G_ms|
          V'_s = [Σg(A_gs/N_gs)] / |G_ms|

原费用 R = Σs(q_s U_s) / Σs(q_s V_s)
对照费用 R' = Σs(q_s U'_s) / Σs(q_s V'_s)
绝对变化 = |R' - R|
相对变化 = |R' - R| / R，仅在 R > 0 时定义
```

内部同时保存两种口径的每目标支出、验收比例、费用和变化。分子分母在同一条件使用完全相同的组集合，零验收组仍贡献费用。不平均 C_g/A_g，也不对各条件费用比值直接加权平均。

每个条件必须除以本条件组数。组在某条件没有任务时不补零，不取全部条件共同出现组的交集。等权发生在条件内：同一组在多个条件出现，其跨条件总权重可以不同。不同模型的来源集合也可能不同，所以不建立来源等权名次或模型关系反转统计。

## 方法反例

以下均为程序验证的合成数值，不是社区业务结果。

- 20组各N=100、A=100、C=100，另20组各N=1、A=0、C=100。原费用为2，来源等权费用为101。删掉零验收组会错误得到1；因其中有零验收组就直接把总体判为无穷也错误。
- 两类组N均为100、C均为100，A分别为100和1。正确费用约1.9802；直接平均各组C/A会得到50.5。
- 每条件各组规模相同时，来源等权与任务量汇总一致，即使不同条件的组数不同。
- 同一组N/A/C同时按倍数增加，其组内均值不变，来源等权费用保持不变；任务量汇总可以变化。这是两个口径回答不同问题，不是谁天然正确。

## 公开披露

公开 API、网页、桌面和私人反馈中的全社区摘录只保留状态、原因、条件最少组数和变化档位：

| 情况 | 公开内容 |
| --- | --- |
| 相对变化≤5% | 变化不超过5%，不细分方向 |
| (5%,20%] | 较高或较低，幅度超过5%且不超过20% |
| (20%,50%] | 较高或较低，幅度超过20%且不超过50% |
| >50% | 较高或较低，幅度超过50% |
| 原费用零且有验收 | 相对变化不适用，不报告0%或未来免费 |
| 零验收、有支出 | 无法计算有限单位费用 |
| 零验收、零支出 | 0/0未定义 |
| 缺项、支持不足、容量不足、数值超界 | 保留对应原因，不当作零变化 |

阈值比较允许比例值 `1e-10` 的浮点偏差；5%、20%、50%的边界归入包含该边界的档位。这不是统计相等检验。≤5%内不额外公开精确相同、近似相同或升降标签。

精确对照值不能沿用上一轮“已公开分项后处理”的披露方式。本轮使用未公开的组矩阵：20组各N=20、A=10，另1组N=40、A=20，总支出T，特殊组支出Y，则来源等权费用 R'=(2T-Y)/420。公开T和精确R'就可求Y=2T-420R'。即使21组全都满足支持要求、隐藏分子，也不能消除这一反推。公开精确相同或极窄容差结论同样可能产生可利用的近似等式。

公开严格白名单不包含均衡分子、分母、精确费用、精确差额、逐组数值或标识。固定档位降低直接反推精度，不提供差分隐私保证；结合历史及外部信息仍可能约束未知值。内部精确报告应继续留在受控管理目录，不作为静态下载文件发布。

## 支持与资源

每个条件至少20组；基础任务量和最大组占比满足原20任务、5组、35%规则。正验收组和未全验收组两个非空子集也分别满足原发布支持。任一条件不满足，该模型的整个附加结果隐藏。这里不删除组，恰好20组可以支持；不套用逐组删除功能的“删后20组”门槛。所有门槛属于项目发布政策，不证明独立性、准确性或完全匿名。

复用 `studyGroupDiagnostics` 一次读取并核对的矩阵，不新增SQL、正文读取、轮询或模型调用。时间为O(E+S)，额外空间为O(S)，E为组条件记录数，S为条件槽数。沿用20000组、8192槽、100000项和16MiB矩阵边界；附加逻辑预算为 `5E+10S+模型数≤1000000`。此计量不是CPU指令数或进程内存硬上限。

使用正项补偿求和，检查下溢、非有限结果及零值语义。已知数值超界使整份附加结果不可用，不保留先完成模型的数值。结构错误仍报错。矩阵容量失败也不使用前缀，完整基础评价保留。只有显式离线评价计算此项，请求读取已有结果。

## 历史与接线

格式2新增可选 `sourceBalance`；旧格式1/2不补字段、不改原摘要。相同目标和事实版本的永久登记不能替换报告ID。新字段适用于未登记的新评价或后续自然变化的事实版本；不能为给旧报告补字段而伪造数据版本。基础 `boards-13`、`public-facts-10` 保留，新方法独立进入公开表示版本。

私人反馈只摘录匹配模型的公开档位，并冻结当时报告、目标与事实版本。它仍属于没有排除本人的全社区背景结果，不能称为私人推荐的独立验证。旧反馈保持原内容。网页、桌面与文字导出共用解释。

摘录还保存从原公开整数分项得到的 `sourceBalanceBasis.positiveSpend/positiveAcceptance`。旧费用摘要可能在既有容差内为0，不能据此改写真实正支出或零验收付费状态。两个布尔值仅记录已经公开分项的零值依据，不新增用户信息；缺少依据或与已保留分项冲突时拒绝新摘录。

## 研究依据与迁移范围

[Kahan等，Estimands in cluster-randomized trials: choosing analyses that answer the right question](https://academic.oup.com/ije/article/52/1/107/6644521)区分参与者平均与组平均，说明权重改变了估计对象。[Williamson、Datta、Satten，2003](https://pubmed.ncbi.nlm.nih.gov/12762439/)研究组规模具有信息时的组规模倒数加权。前者原文由独立评审核对，主代理查阅出版页面检索记录；后者核对PubMed原始摘要。

本项目仅迁移“明确加权对象、先算组内均值”的原则。社区自愿上传不是随机试验；论文的无偏性、因果效应、标准误和精度结论不能直接迁移。费用比值、公开档位、门槛和容量是本项目设计。未使用 `cumcm-statistics`。

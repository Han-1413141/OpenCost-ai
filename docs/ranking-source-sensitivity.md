# 固定选型后的来源影响

版本：`source-sensitivity-internal-1`（私人精确报告）、`source-sensitivity-1`（公开档位）；实现日期：2026-10-15。对应清单 S-07 的来源集中度和逐组删除部分。

这项分析回答：在已经选定模型、Harness 和任务构成后，拿掉任意一个已知关联来源组，单位验收费用会变化多少。用户据此了解结果是否集中在少数来源，决定是否需要积累更广的观察。它不改变榜单、不重新选择配置，也不把变化较大的来源判断为作弊。

不同模型拥有的来源数量和构成可能不同；组数较多通常会减小单组删除的影响。因此不能用这项结果给模型再排一个“稳定性榜”。低影响也不证明未来费用稳定、失败不会出现或未知来源之间没有关联。

## 计算对象与公式

使用来源留出评价侧的数值矩阵。每条组条件记录只有结束根目标数 N、验收目标数 A 和归属支出 C。关联组继承已知持有人与可信来源关系的连通分组；不等于独立真人。任务类型、权重、模型版本、Harness 型号及版本、套餐和费用证据口径沿用冻结选择，不在删除后调整。

模型 m 只遍历自身在已选配置中有观测的组集合 G_m。其他模型独有的组不计入 m 的删除次数，避免制造大量没有变化的删除。

```text
对每个 g ∈ G_m，同时移除其全部任务条件中的观测：
N_s(-g) = N_s - N_gs
A_s(-g) = A_s - A_gs
C_s(-g) = C_s - C_gs

R(-g) = [Σ_s q_s C_s(-g)/N_s(-g)] / [Σ_s q_s A_s(-g)/N_s(-g)]
R     = [Σ_s q_s C_s/N_s] / [Σ_s q_s A_s/N_s]

最大绝对变化 = max_g |R(-g) - R|
最大相对变化 = 最大绝对变化 / R，要求 R > 0 且全部删除结果有限
```

这里保留失败目标及其费用，先算各条件的每目标投入和验收比例，再按固定构成形成总体比值。不对各来源的单位验收费用直接取平均。一个组跨多个条件时一起删除，不能分别删除后挑选影响最小的条件。各条件结果始终使用原权重。

费用单位和适用口径来自原报告。实际支付、订阅分摊和 API 等价费用不合并；本功能不读取支付账户，也不产生新价格或任务量。

## 零、未知和无界

内部每次删除分别归为有限、零验收有支出、缺条件、0/0 未定义。全部次数都参与诊断，不删除无界或未知结果后再计算一个有限范围。

| 情况                         | 处理                                                   |
| ---------------------------- | ------------------------------------------------------ |
| 原费用为零，原验收为正       | 可记录零绝对变化；相对变化和费用占比不适用，不填 0%    |
| 原验收全部为零               | 不生成有限单位费用、删除范围或相对变化；保存零验收状态 |
| 删除后验收为零且支出为正     | 已知没有有限费用上界，单独标记                         |
| 删除后缺少必需条件，或为 0/0 | 无法判断；内部范围保留非负未知范围，不改称高影响       |
| 所有删除结果相同             | 公开为不超过 5% 档，不宣称总体方差或未来风险为零       |

发布支持规则通常会挡住导致缺条件、零验收的单组删除，但计算契约仍明确区分这些状态，避免未来接入或数据导入时把它们当零。

## 原始和删除后均须满足支持

原基础评价要求每个条件至少 20 个结束目标、5 个关联组、最大组任务占比不超过 35%。来源影响要求原始每条件至少 20 组；由于删除后也要保留至少 20 组，恰好 20 组的原始数据只能显示删除后支持不足。

每次删除后，所有受影响条件重新检查：

1. 至少 20 个结束目标、20 个关联组，最大组任务占比不超过 35%。
2. 有正验收的组构成的子集，若非空，须有至少 20 个目标、5 个组、最大组任务占比不超过 35%。
3. 尚未全部验收的组构成的子集，若非空，须满足同样的 20 目标、5 组、35% 规则。

有一次删除不满足，就隐藏该模型的全部删除数值和集中度。没有“仅保留支持充足的删除”这一分支，也不因为某次结果更好而发布它。未被删除影响的条件保留已通过检查的原始状态。

这些门槛是项目发布政策，不能当作论文给出的可靠样本量证明，也不认证统计独立性。

## 私人精确结果与公开档位

私人管理员报告保存完整诊断：模型自身组数、四类删除次数、基础费用、删除费用范围、最大绝对和相对变化，以及各条件内单组任务量、支出、验收数的最高占比。该报告仍须放入受控私人目录，不能作为公共静态文件发布。

公开报告采用独立的严格字段白名单，仅保留状态、原因、原条件最少组数和以下固定档位。新增未声明字段直接拒绝，不将私人对象展开后发送到 API。

| 指标                           | 固定公开档位                                                   |
| ------------------------------ | -------------------------------------------------------------- |
| 最大相对费用变化               | ≤5%、(5%,20%]、(20%,50%]、>50%，另有未知、无界、零基准、零验收 |
| 条件内单组任务量最高占比       | ≤10%、(10%,20%]、(20%,35%]                                     |
| 条件内单组支出或验收数最高占比 | ≤10%、(10%,25%]、(25%,50%]、(50%,75%]、>75%，总量为零时不适用  |

最高占比分别在各条件内计算，再跨条件取最大；三项最大值可能来自不同组，不能把它们拼成同一个用户的画像或相加。

费用影响档位采用 `1e-10` 的比例值比较容差，处理有限精度计算在 5%、20%、50% 边界上的微小偏差；容差内归入包含该边界的档位。这不是按展示小数位提前四舍五入。内部原始计算值保留，单位是比例而非百分数值。

精确极值即使经过组数门槛也可能反推单组金额。例如单条件 21 组，每组 N=20、A=10，总费用 2100，删除组 g 后单位费用为 `(2100-C_g)/200`。公开最小删除费用 9.25，就能推出最大单组费用 250。因此公开结果不包含精确删除范围、变化量、峰值占比、删除次数、模型自身组集合大小或组标识。

固定档位降低这类直接反推的精度，不提供差分隐私保证；结合其他公开信息仍会约束可能值。固定目标、事实版本和永久报告登记继续限制同版本反复换结果，不提供按任意组标识删除再查询的接口。

## 资源与兼容性

矩阵与原重采样共同使用一次数据库聚合读取，并在同一事务核对每个条件的 N/A/C 和组数。不会再次读取任务正文、提示词、代码或账号。不新增轮询、常驻计算或模型调用；仍由管理员显式启动离线评价，默认不配置活动评价集合。

计算预先维护各支持集合的总量、组数及最大和次大任务量，保留不同组的相同峰值。删除时只更新受影响条件，不对剩余全部组反复扫描。时间复杂度为 `O(E + Σ_m |G_m| × |S_m|)`，额外空间为 `O(E + S)`；E 为组条件记录数，S 为条件槽数。

沿用最多 20000 组、8192 条件槽、100000 组条件记录和 16 MiB 数值矩阵预算。来源影响另外设置 4000 万逻辑工作单位，预检与运行中均计数。容量不足时整份附加诊断返回未计算，不使用前缀；完整基础评价保留。重采样与来源影响各有工作预算，同时受原批处理进程的 30 秒、V8 堆 256 MiB、SQLite 原生分配 128 MiB 限制；这些不是整个进程 RSS 上限。

`boards-13` 纳入当前结果版本，来源影响在公开格式 2 中为可选字段。旧格式 1、未含来源影响的旧格式 2 保留原字段与摘要，不补写缺省值。新报告的来源影响模型范围、最少组数、零费用及零验收状态须与基础评价一致；私人诊断的基础费用还要与同模型点估计一致。API、首页、比较页和导出共用同一投影。

网页通过可展开的“来源影响”展示档位、集中度和限制，不增加新的名次。桌面私人反馈尚未消费这套来源留出报告；真实界面和独立机器安装另行验收。难度分级以及自动采集、生成、上传、登录启动仍默认关闭。

## 已覆盖的验证与研究来源

验证使用隔离数值记录、临时 SQLite 和本地 CLI。解析案例覆盖跨模型独有来源、同组跨条件、零费用、零验收、删除后支持变化、20 组边界、公开字段限制、容量回退和历史格式。80 组预设合成情景通过独立实现直接删组重算，对照全部有限范围；它们检验计算一致性，不证明真实业务预测精度。

独立只读评审指出 5% 边界的浮点误分档，已加入原始反例以及 5%、20%、50% 等值与超出边界的对照。已有实验的重采样覆盖结果不因本次新增影响诊断而改变，也没有为了本功能重复执行上一阶段的 1200 万次实验。

方法参考 [statsmodels 官方 OLSInfluence 文档](https://www.statsmodels.org/stable/generated/statsmodels.stats.outliers_influence.OLSInfluence.html) 中逐观测删除后比较结果的思路。本项目按关联组删除，并重新计算固定构成费用比值；没有套用 OLS 回归的 Cook 距离、DFFITS 阈值或标准误结论。

[NIST Dataplot 的影响曲线说明](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/inflcurv.htm) 用添加单点后的统计量变化观察影响。本项目借鉴观察扰动敏感性的思想，采用上述明确的逐组删除定义；不声称复现了该添加点算法或获得其稳健性证明。两项官方文档均于 2026-10-15 查阅；档位、支持门槛与预算是本项目设计。

任务权重变化、来源平衡权重、选择侧重选稳定性、未知任务族关联和真实时间留出仍属于后续工作。本功能只完成 S-07 的固定选型来源影响部分。

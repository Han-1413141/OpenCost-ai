# VBTI 活动与工作画像

VBTI 指 Vibe coding Type Indicator，是根据用户上传的结构记录生成的趣味工作画像，不是人格量表。独立活动首页 `/vbti/`；使用说明 `/vbti/test/`；私人类型结果 `/vbti/result/`。三个地址可直接访问，使用独立导航和像素风格；旧的 `#vbti`、`#vbti-test`、`#vbti-result` 书签会转到新地址。原首页、上传和反馈入口保持可用。

## 入口与流程

网站侧边提供小型像素角色图标，点击进入独立活动页面；小屏幕固定在角落，不占排行榜首屏。活动首页使用像素标题、神秘角色站台和黑影图鉴，介绍类型、六维图、模型与 Harness 推荐、套餐推荐、额度历史变化和同类额度位置。复杂说明放在第二页。普通点击在同一应用内切换独立路径，当前访问凭证保留在内存，不复制到路径、查询参数、历史状态或浏览器持久存储；刷新或另开标签页仍需登录或打开私人反馈链接。

第二页默认近三天，扩展脱敏分析默认开启，可关闭；额度监测与参与统计仍关闭。用户选择后复制包含固定 GitHub 提交的现有 opencost-contribute Skill 提示词，由 Harness 按原采集流程说明来源、生成预览、确认并上传；不因访问活动页读取本机会话或调用模型。超过三天的选择提示整理额度。自动运行和自动上传不随活动开启。

上传后的私人反馈链接仍沿原安全入口读取并移除地址栏凭证，用户点击“VBTI 类型结果”进入角色与雷达图。没有新建身份系统，不向公开页面泄露报告。图鉴黑色剪影和累计规则见 [角色说明](feedback-persona-art.md)。

## 六维数值

六维是对已有记录的二次处理，不是模型自由打分，也不用于正式性价比排序。

| 数值 | 计算 |
|---|---|
| 分身指数 | 全部层级子代理数 / 去重代理总数 × 100；每个根代理分别扣除。没有根代理数时留空，不按总数减一推算。 |
| 工具密度 | 工具调用数/用户轮次，指数 100×密度/(密度+4)；无有效分母留空。 |
| 任务拆解度 | 每项完整结构记录先计算 100×(部分数−1)/(部分数+3)，再等权平均；重复步骤不加任务数，大量拆分只影响该项。 |
| 探索浓度 | 含研究知识、检索、统计或仿真要求的任务比例；每任务最多计一次。 |
| 较真指数 | 含形式验证、形式化论证或来源可追溯要求的任务比例；每任务最多计一次。 |
| 跨界浓度 | 含跨系统集成或多模态对齐要求的任务比例。 |

饱和函数的 4 是公开的显示尺度，不是统计校准阈值。后三维仅使用能确定相应条件的任务作分母；明确命中可计入，不能判定是否命中的记录留空，不把未知当否。维度原始值、分母、公式可展开查看。数据不全时只画已知点与相邻已知边，不把缺失轴拉到零点。人物趣味名与数值名分开。

## 数据与隐私

本站接收枚举、计数、范围、公开产品型号等结构字段；原始任务、对话、源码、路径和密钥不进入摘要。用户在上传前检查完整字段，分享范围单独选择。原始材料仍由用户所选 Harness 和模型服务处理，不能把网站不接收原文描述成任何第三方都不处理原文。私人访问凭证继续保留现有身份隔离；统计采用既有条件、去重与样本门槛。

## 判定规则修订（2026-10-16）

要求类维度保留模型提取、日志、程序、用户填写等来源计数。部分覆盖能确认命中，但未命中不得当作确定的否。少于 3 项已知要求或少于 3 轮对话标为少量记录，仍展示原值；不以虚构先验填充缺项。数值为描述性比例与公开展示转换，不宣称校准能力或统计置信度。

主要角色使用数值倾向排序：排序分 = 倾向值 × 已知覆盖率 × n /（n + 3）。要求类倾向值为命中比例，工具与对话使用每轮或每条工作的密度转换；每种数值保留自己的分母。n 是对应记录数。多个条件重合取证据最充分的一个分支，不把次数相加。缺少分母的角色仍可显示已知特点，但不参与主要角色排序。与最高分相差不超过 5 分且达到最高分 85% 的角色并列展示，固定顺序只用于完全同分。上述权重是公开活动规则，不是经验校准的心理测量模型。

个人图鉴暂沿用原有证据解锁规则，新方案在 [角色解锁候选方案](vbti-unlock-options.md) 中等待选择。公开图鉴按参与统计且已关联账号的去重人数展示；满 100 个账号才公开名称与条件，未知人数显示统计中。账号数不等于验证过的自然人数，私人记录不因页面访问进入公开统计。

日常成就独立显示，使用最近 30 天中可读取的不同日期与最新修订，不把重复上传算成新日期。常用 Harness 或模型标签需要至少 7 个记录日且覆盖半数记录日；历史不完整、型号缺失时不推算常用产品。贡献报告只有当前任务记录时，展示当前使用标签。模型型号只从结构化日志中的公开型号白名单读取，私人别名、任务原文和整理摘要所用的模型不冒充工作模型。成就描述当前反馈能够读取的记录，不宣称永久保存所有历史称号。

VBTI 的 GitHub 登录保存发起页面及语言，回调后返回同一 VBTI 页面。已有有效会话直接进入对应页面；按钮显示“已登录 · 查看我的类型”。返回目标仅允许站内公开页面，不携带私人凭据。

所有新增上传字段只允许枚举、计数、布尔值和缺项。模型不能填写程序测量、代码报告或来源认证；代码分析沿用已选择的本地文件/报告通道。自动运行、自动上传、公开统计均不因扩展分析开启而改变。

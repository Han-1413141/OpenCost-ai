## 已落地与未落地

已落地：`task-observations-1` 可选结构观察；`task-insights-1` 本人描述指标；`source-support-1` 来源集中度与受门槛约束的分位；根目标匹配覆盖；最低 Harness 选择依据；前端按任务排名和缺测显示；默认关闭的本地公开锚点 Rasch 原型。具体契约以 [当前方法说明](../../analysis-methodology.md) 为准，研究文件中的候选类型不等于已全部采集。

尚未具备的数据与验证：真实同题跨配置响应矩阵、去除任务族相关的校准、样本外预测、经验区间、因果节省、可靠的混合任务套餐容量。没有启用生产难度或自动采集，不给未经校准的统一 0–100 分数。

AA 官方[方法页面](https://artificialanalysis.ai/methodology/intelligence-benchmarking)和[API 文档](https://artificialanalysis.ai/api-reference)另于本轮查阅。仅作为外部任务和环境下的参考，按接口保存的方法版本解释，不把当前网页方法回填旧指数。

模拟测试只检验实现、边界和显示，不验证现实任务分类准确率；既有真实社区为空时保持为空。

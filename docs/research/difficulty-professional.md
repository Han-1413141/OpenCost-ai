# 专业与服务任务的难度、工作量资料研究

检索日期：2026 年 10 月 12 日。范围包括办公、商业运营、法律材料、金融材料、科研证据综合，以及农业、地理、公共政策和社会科学的覆盖检查。来源及实际阅读范围见 [difficulty-professional.json](./difficulty-professional.json)。本轮是按领域进行的一手资料检索，尚未达到系统综述的穷尽性搜索条件。

## 可直接采用的结论

难度分级确有研究，但没有从这些资料中找到可直接拿来覆盖所有 AI 任务的统一刻度。不同框架分的是职业技能、认知能力、工作流指令条件或领域内任务，必须保存其适用范围。

| 资料 | 可以采用的设计 | 不直接移植的部分 |
| --- | --- | --- |
| [O*NET 量尺](https://www.onetonline.org/help/online/scales) | 判别维度使用具体描述锚点，重要性、频率和要求水平分开 | 职业均值、变量间的 0–100 分不能当本项目全域难度 |
| [WorkArena++](https://arxiv.org/html/2407.05291v2) | 原子部分与完整工作流分开，指令显式程度、检索和可行性分别记录 | L2/L3 是相同工作流在不同指令条件下的分级，不能据此按工具步骤数给所有任务定级 |
| [AgriBench](https://arxiv.org/html/2412.00465v2) | 多模态条件和任务要求分别记录；感知、计数、推断、方案支持有不同义务 | 论文的农业五级不等于已经标定的跨领域等级 |
| [LegalBench](https://arxiv.org/pdf/2308.11462) | 法律推理类型细分为争点、规则、适用、结论、解释、论述理解 | 主要法律背景及非穷尽类型不能当各地区的专业资格或统一难度 |
| [FinBen](https://arxiv.org/html/2402.12659v2) | 金融提取、文本分析、问答、生成、风险、预测、决策分别评价 | 历史模拟收益、准确率和业务结果不合成一个固有难度数字 |

这些映射是本项目的设计推断，资料没有发布 OpenCost 的评分公式。每项需要先从原要求中找到依据，复杂的实际执行方法、更多 Token、耗时和失败重试只影响消耗记录。

## 目录覆盖采用三条轴

建议把“做什么”“涉及什么主题”“在什么条件下做”分开。工作活动保持软件、表格、证据综合、翻译、图像等现有分类；主题可另记农业、地理、政治、考古等；时点、区域、权限、输入模态和环境归入条件。这一设计借鉴 [ISCO-08](https://isco.ilo.org/en/isco-08/) 对知识、工具、材料和产出的区分，并用 [Frascati Manual 表 2.2](https://www.oecd.org/content/dam/oecd/en/publications/reports/2015/10/frascati-manual-2015_g1g57dcb/9789264239012-en.pdf) 检查学科遗漏。

例如“用代码分析农田遥感数据”有算法/数据处理活动、农业/地理主题和多光谱/时序条件。它仍然只有原要求确定的独立目标和成果；添加标签不增加工作量，也不把同一次执行费用复制三遍。

| 领域 | 本轮建议补充的活动或主题 | 需要保留的判别条件 |
| --- | --- | --- |
| 办公 | 跨文档更新、跨表公式、复杂格式转换、跨应用流程 | 公式/引用依赖，版式及数值保持，最终状态，异常恢复 |
| 商业与服务 | 配置报价、线索商机、工单分流与升级、排班、补货、跨系统对账 | 规则及例外，权限边界，共享状态，目标可行性，回执 |
| 法律材料 | 争点识别、规则提取、条件适用、解释、论证理解、合同条款定位 | 地区与规则版本，事实/条款关系，例外与引用，未确定事实 |
| 金融材料 | 实体关系和数值提取、情绪与论证、证据问答、披露摘要、信用欺诈及预测材料 | 文字/表格证据，币种期间，公式链，假设、口径及核验范围 |
| 研究与社会科学 | 证据缺口图、定性编码与主题综合、混合方法、调查与政策评价 | 分析单位、研究/报告对应、纳排、缺失冲突、推断成立条件 |
| 农业与兽医主题 | 作物育种/保护、土壤、林草、畜牧乳业、水产渔业、兽医材料、食品追溯 | 地区季节、物种及生长条件、生物不确定性、现场证据边界 |
| 地理与环境主题 | 遥感、GIS、气候、地质、水文、海洋、城市规划、灾害材料 | 坐标单位，空间/时间尺度，波段传感器，缺失观测和泛化范围 |
| 人文主题 | 历史、考古、哲学伦理、宗教研究、文学语言、艺术史 | 来源身份和时代语境、竞争解释、论证和翻译保持 |

农业目录还应参考 [AgriEval](https://arxiv.org/html/2507.21773v1) 的中文领域覆盖，但考试知识题与田间实践必须分开。[GEO-Bench-2](https://arxiv.org/html/2511.15658v2) 按分辨率、波段及时间性区分模型能力，支持我们按具体任务条件推荐模型，而非为一个模型永久选同一个 Harness。

## 工作量与验收

专业工作仍按四项并列统计：独立验收目标、原要求组成部分、不同单位的最终成果、实际执行消耗。不能将来源数、页数、工具调用、模型对话和难度加成混为统一成果量。

- [SpreadsheetBench](https://arxiv.org/html/2406.14991v2) 支持按实际改后表格和边界情况核验，重复运行不新增记录或最终成果。
- [τ-bench](https://arxiv.org/pdf/2406.12045) 提醒：最终状态正确仍可能违反确认规则。目标验收、政策遵循、操作授权分别保存；重复可靠性与单次完成率分开。
- [CRMArena-Pro](https://arxiv.org/pdf/2505.18878) 包含单轮、多轮、不同业务与保密义务。该基准使用合成企业沙箱，不能伪装成真实社区数据。
- [CUAD](https://arxiv.org/pdf/2103.06268) 的条款提取与咨询不同。文本交付完成不能改写成法律意见已获认可。
- [FinQA](https://aclanthology.org/2021.emnlp-main.300/) 和 [ConvFinQA](https://aclanthology.org/2022.emnlp-main.421/) 支持记录证据及数值依赖；多轮次本身不提高难度。

证据综合要区分去重后的来源、报告和独立研究。同一研究的多份报告不能自动变成多项独立证据。方法记录参考 [PRISMA 2020 扩展清单](https://www.prisma-statement.org/s/PRISMA_2020_expanded_checklist-w7ra.pdf)，社会政策还参考 [Campbell Standards](https://www.campbellcollaboration.org/methods/standards/)。这些是方法及报告义务，不能凭满足清单就宣布研究结论正确。

调查和定性工作参考 [AAPOR 披露要求](https://aapor.org/standards-and-ethics/transparency-initiative/)。脱敏数据只保留方法枚举、分析单位、规模、缺失/冲突和核验状态；问卷原文、受访者信息、业务名称和原始证据在本地留存。公开资料的披露建议不是让本插件上传隐私的授权。

## 当前实施边界

本轮资料支持细化目录和结构化义务，但没有给生产难度分级提供完成的经验校准。保持默认关闭，程序现在可计算有依据的计数、依赖、去重、费用及证据覆盖；分数、跨领域等级与难度准确率继续为空。

在开启分级前，按领域和细类型建立原要求样本、独立标注、任务家族隔离的保留集，并预先冻结评价条件。目录保留未知项和版本扩展入口。本文和 JSON 已明确哪些资料只读摘要或目录，未读内容不会作为已经核验的规则。

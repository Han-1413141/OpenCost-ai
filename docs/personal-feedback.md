# 上传后的个人反馈

## 网页入口、直接链接与账号关联（2026-10-16）

正式入口为 `https://opencost-ai.com/#feedback`。“我的记录”也提供进入按钮。页面按需分页展示工作与费用、每日工作摘要、订阅与额度三种上传，选择后读取对应的原始反馈；每页 20 条，接口最多 25 条。列表只读小型元数据，按账号最多 20 个关联身份及现有索引查找，不扫描历史正文，不定时刷新。

三个上传 SDK 的回执新增 `feedbackUrl`。CLI 同时显示直接访问链接和完整回执位置。链接将 OpenCost 访问密钥放在 `#feedback?key=…&kind=…&recordId=…`，HTTP 请求不携带该片段；页面在 React 和语言初始化前消费并清除地址栏中的密钥，不将其写入浏览器持久存储。持有该链接相当于持有此身份的访问凭证，可访问及上传相应记录；不要公开分享。GitHub 账号复制的链接打开账号统一列表，旧凭证链接定位具体记录；重复日记指向实际保存的原记录编号。

导入凭证或打开链接后，已登录时自动关联；未登录时可立即查看，并可在 10 分钟内登录完成关联。服务端同时验证凭证、会话、Origin 和 CSRF，关联表只保存内部身份与随机关联编号。跨账号占用、账号专属凭证和超过 20 个关联会明确拒绝；可手动解除。关联只统一访问，原始数据、旧凭证、费用归属和历史反馈不合并或重写。

首屏优先展示工作与投入，详细采集范围及后续行动可展开。日记优先展示工作条目、用户轮次、摘要整理输入/输出和未知实付。缺少比较依据时显示“数据不足，稍后再看”，已知数据保留；临时报告可手动再读，冻结历史报告继续反映原生成时点。不因提示缺项重新上传摘要。

反馈展示工作量、费用、Token、额度、完成情况、时间、重试和返工，并在存在可比记录时给出模型、Harness 或套餐建议。反馈使用程序计算，不额外调用模型。

## 在哪里查看

网站“我的记录”、桌面应用“个人反馈”及 CLI 成功回执均可查看。读取历史反馈须使用对应账号或访问凭证。`GET /api/feedback` 读取指定记录，`GET /api/feedback/mine?limit=20` 读取最近反馈。

## 怎样阅读

- 工作量按任务类型和成果单位展示，Token 与对话轮次作为投入指标。
- 实付、订阅分摊和 API 等价金额分开。失败、重试与返工的费用保留。
- 额度观察区分使用、重置、赠额、到期与滚动恢复。
- 同类比较对齐任务条件、时间和费用口径，显示参照范围与缺失项。
- 进行中的任务与已结束但未完成的任务分别记录。

单次记录提供初步反馈，连续观察一周或一个月更适合比较。缺少实付、验收、材料规模或可比样本时，对应指标显示未知，保留已有描述统计。

## 方案建议

建议依据同类工作的已观察成本、完成情况、时间与额度条件，展示对应模型、Harness 或套餐。按实际任务需求阅读推荐，价格采用记录期版本。

## 私有范围

反馈属于上传身份，公开统计使用达到样本要求的分组结果。反馈不包含其他用户的个人记录或账号信息。

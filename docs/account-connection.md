# 本机记录与 GitHub 账号

关联一次本机上传身份，已上传及今后上传的工作摘要、工作日记、订阅额度记录和私人反馈即可在 GitHub 账号下查看。网页、桌面应用和多个 Harness 可以关联同一个账号。

## 桌面应用

保存上传站点，在“个人反馈”点击“关联 GitHub 账号”，到打开的网页完成登录，再点击“检查账号关联”。应用同时关联自己保留的本站点历史凭证；不会扫描其他应用的文件夹。

未上传的本地日记仍保存在本机，选择上传后才进入账号。关联不改变自动生成、自动上传、监控或公开统计开关。导入新凭证时，应用保留旧凭证的加密副本；更新前已被覆盖、删除的凭证需要用原备份恢复。

## Skill 与命令行

使用生成摘要时的同一个运行目录和上传凭证：

```sh
npm run contribute -- account-connect --endpoint https://opencost-ai.com --out .local/connect.json
npm run contribute -- account-status --endpoint https://opencost-ai.com
```

在本机浏览器打开 `.local/connect.json` 内的 `url`，完成 GitHub 登录。链接一次有效，10 分钟过期。不要分享这个文件。已有导出凭证可在命令末尾加 `--credential .local/opencost-access.json`，独立密钥文件使用 `--identity PATH`。所有后续上传继续使用同一凭证。

不同 Harness 可分别关联同一个账号，或共用用户明确导出的同站点凭证。每个账号支持关联 20 个身份。同一身份不能同时关联不同账号；可在网站管理已有的关联。关联不复制历史摘要，不重新计费，不把各身份的费用重复相加。

## 模型切换记录

逐次调用保留模型、同代理的顺序或时间与实测用量。程序生成按代理区分的阶段：A → B → A 为三个阶段、两次切换；子代理和各层后代独立统计。个人反馈和工作日记可查看每阶段的模型、观察时间、输入/输出 Token 与已知 API 等价费用。

Codex 累计用量按相邻计数差分，重复读数不再相加；缺少基线或计数回退时保留未知。DSH 保留导出的调用时间；Claude Code 和 OpenCode 使用消息中的模型及用量。同一任务参与的所有模型仍保留为组合，任务完成不只归给最后一个模型。

旧日志缺少顺序、模型或用量时，完整切换次数或对应字段为未知，已知部分单独显示。不根据总 Token 比例分摊不同模型的用量，也不用模型切换推断套餐实际扣款。

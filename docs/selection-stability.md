# 选择侧重选稳定性

日期：2026-10-15。对应清单 S-04/S-05/S-06、R-04/R-05、F-01 与 U-01/U-06 的部分工作。方法 `selection-stability-1`，随显式离线 `ranking-study evaluate` 运行；不在网页访问或每日上传时计算，不增加模型调用或轮询。构建与运行状态见 [项目状态](status.md)。

## 回答的问题

现榜按同类工作分别选出每个模型单位验收费用最低的 Harness。来源留出先冻结选择，再在另一部分数据评价该配置。[固定选型后的重采样](ranking-resampling.md) 只观察评价侧的费用变化。

本方法增加另一项观察：原选择侧来源构成改变时，按相同规则是否仍然选中原 Harness，原模型是否仍位于最低费用集合。选择侧和评价侧分开；原评价结果、点值及费用范围不因此重算为新的验证结论。重选频率没有被解释成真实获胜概率，也不用于重新排序原榜或删除不稳定的候选。

## 输入与规则

输入仅为同一事实快照内选择分区的数值矩阵：已知关联组、模型/任务条件/完整配置、已结束根目标数 N、验收数 A 和全部归属支出 C。任务条件及权重沿用原目标；所有模型和条件共享每次组抽样权重。关联组包括当前选择范围中的来源组，即使某个组没有本次候选配置的观测，也保留空组，不因只看某一模型而改变抽样总体。

候选集合固定为原选择侧已经满足公开支持且至少一次验收的配置；原零验收配置不可能靠重复这些观察得到一次成功，因此不进入此有限重选集合。新配置、未公开支持的配置和未观察到的未来成功均不纳入。原先未达到完整模型选择资格的模型不参与最低模型比较；原先已有资格但评价支持不足的模型会使该比较缺项，不能偷偷只比较剩余模型。

使用与原重采样相同的 xoshiro128** 发生器及无模偏拒绝索引；版本不改变原固定选型随机流。新种子独立绑定方法、费用/证据范围、月份、事实版本和分组摘要，不使用目标名称、studyId、准备时间或评价结果换随机流。这里的随机数只用于可复现数值计算。

## 每次重选

预定1000次，按组有放回抽取原组数；同组跨任务、模型、配置的观测一起加权。重复抽到同一已知组不会增加独立来源数。每个候选重新检查至少20个结束目标、5个实际出现的已知组、最大组任务占比35%，并要求 A>0。

每个任务条件内，排序依次为 C/A 较低、A/N 较高、已出现组数较多、N较多、完整配置的固定规范顺序。沿用现有数值与并列规则，不按完成率档位重新分组。每条件可选择不同 Harness。

模型总费用沿用固定发起任务构成：

```text
平均发起支出 = sum(q_s * C_s/N_s)
标准化验收比例 = sum(q_s * A_s/N_s)
单位验收费用 = 平均发起支出 / 标准化验收比例
```

不平均各条件的 C/A，不删除失败支出，不重新分配缺项条件的权重。原可比模型在某次重复无法完整重选时，该次最低模型比较未知；不挑剩余模型后声称它保持领先。

## 保留的统计

- 每条件：是否仍选择原完整配置；原配置是否仍属于最低费用配置集合，后者包含费用并列。
- 每模型：全部任务条件是否仍选择原配置组合；是否属于原可比模型集合中的最低费用模型，包含模型并列；是否无法完成全部条件重选。
- 内部每项保留 yes/no/unknown，所有重复均进入1000次分母。某条件已确定改变时，整体组合即已确定改变，不因另一条件缺项抹掉这个已知变化。

公开只给出粗粒度频率上下界。已确认保留 y 次、未知 u 次时：

```text
下界 = floor(y / 100) * 10%
上界 = ceil((y + u) / 100) * 10%
```

例如701次保留、199次改变、100次未知，公开70%—90%。这个范围同时包含未知重复和10个百分点向外取整；不是置信区间。精确70%与本次100%可以作为这批重复的事实保留，不能推为未来必然保持。多个模型的并列频率不必相加为100%。

## 发布、历史与用户反馈

任一候选不足20个来源组，或候选的已验收/未全验收来源分布未满足既有发布条件时，整个模型的频率不公开；不能先排除这个候选再得到更稳定的比例。20组是本项目发布政策，不是统计可靠性的理论保证。其他模型的整体最低比较在原集合缺项时也不输出。

公开字段为原模型/条件、固定方法元数据、状态、原因及频率档位，不含组ID、原始次数、费用极值、替代配置名称或逐组数值。这不提供差分隐私或来源真实性认证。原始数值矩阵只在离线进程内使用，私人报告保留精确累计次数和工作预算，不新增原文、代码或提示词读取。

附加字段随 `ranking-source-holdout-public-2` 的新报告保存，并进入原报告内容摘要。旧报告缺字段仍可读，不回填新频率，不覆盖原ID、数值和发布登记。当前事实版本变化仍使旧报告停止匹配当前榜单；历史文件保留。

网页显示整体配置保留、最低模型与未完成重选频率；各任务条件可展开，每页16项，折叠时不创建全部条件行。个人反馈与桌面保留整体组合和当前匹配的单项条件，显式标 `whole_route_and_matched_condition`；它仍是全社区背景，没有排除本人，也不验证该私人推荐。全部冻结信息跟随首次反馈保存。

## 性能与检查

复用现有来源划分和就绪事实；按模型/条件一次索引选择侧聚合，再读取有界数值矩阵，不按候选逐条读取正文。最多128模型、8192配置槽、20000组、100000非空组/配置项、16MiB矩阵读取，附加算法2000万主要工作单位。预检或运行达到边界时撤去整份重选统计，不返回先完成模型的数值；原完整基础评价和原附加方法保留。离线子进程原30秒及内存边界仍适用于整个批处理，不是生产吞吐或进程RSS硬上限。

隔离测试包括共同组权重、已知费用优势、来源费用交叉的二项分布解析值、费用并列与次级规则变化、零验收/支持不足、全部重复分母、模型并列、固定权重比值、输入顺序、容量与公开投影。实际离线入口验证只改变评价侧费用不会改变重选频率，改变准备时点和studyId不会换流；反馈摘录和两端共享组件使用同一协议。精确结果见项目状态。

## 依据与适用范围

[Cawley与Talbot，JMLR 2010](https://jmlr.org/papers/v11/cawley10a.html)说明有限样本选型准则的波动可能导致选择偏差。这里增加重选观察，同时保留选择/评价隔离；没有把本方法称为该偏差的校正量。

[scikit-learn官方嵌套交叉验证示例](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)说明配置选择与最终评价混用会影响估计。本项目保持评价集不参与重选；没有实现嵌套交叉验证，也没有引入scikit-learn。

成组重采样借鉴既有[观测组方法](ranking-resampling.md)的依赖保留原则。结果以这些已观察来源、支持配置和旧价格为条件，不覆盖未知任务族依赖、未来价格、未来任务或完整选择过程的总体抽样分布；后续时间留出与校准研究仍另行推进。没有使用cumcm-statistics。

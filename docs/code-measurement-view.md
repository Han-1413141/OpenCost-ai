# 查看代码结构与前后变化

更新：2026-10-15。本功能落实M-01、M-03及M-04的本地数值入口，不开启生产难度评分，也不改变上传或排名。

## 网页与应用入口

网页进入“计算方法与数据标准 → 复杂度研究”，或“脱敏工作量 → 分领域工作标准”；应用进入“统计标准”。点击“打开本地代码结构”才加载面板。初始页面不读取文件、不运行解析器。选择一个数值报告即可查看，两份可以比较；关闭或清空会丢弃页面中的报告、确认与正在读取文件的结果。文件名、路径、UUID和原始JSON不显示，数据不写入浏览器存储，不发送报告、不请求外部模型或服务。打开面板只加载站点或应用自身的静态资源。

只接受不超过256 KiB的UTF-8 JSON数值报告：Python的 `python-code-measurement-1`、JS/TS的 `code-measurement-set-1`，或 `patch-measurement-1` 补丁计量。JS/TS报告由 `measure-code-set` 生成；旧JS/TS单文件 `code-complexity-1` 缺少清单范围和要求修订，本入口不接收。Python单文件报告可查看，没有要求修订时不作前后比较。补丁报告由 `measure-patch` 在本地生成，不能代替前后代码快照。路径清单、源码、原始补丁、任务原文和带未知字段的对象一律不采用，错误使用固定说明。

面板分语言显示文件数、函数数、圈复杂度、控制嵌套与参数的数量、最小值、中位数、P90、最大值及均值，保留覆盖、重复、未测得数量及原因。Python具名函数与JS/TS函数语义不同，分别标明方法及版本；无函数时分布显示无函数，未测得不能当零。Python行数存在定义交叠，不把所有行数字段相加。各项数值不是任务难度或完成量奖励。

## 同范围比较条件

程序要求两份报告均测量完成、范围声明完整且没有未测得文件，原要求修订UUID一致，阶段分别声明为执行前/执行后。语言集合、解析算法、解析器版本必须相同，Python解释器版本也必须相同。用户还需确认两份报告针对相同模块范围，并完整包括该范围内的新增和删除文件。输入文件顺序及重复选择数量可以变化，不以文件数必须相等代替范围一致。

这一确认属于用户声明：工具没有源码标识，不能自动认证范围或还原同一函数。测量时间只表示何时运行工具，不能证明代码来自任务执行前；允许用户晚些时候测量先前保存的固定版本。因此比较不依赖两个测量时间的大小。应明确选择保存好的前后版本，不能拿当前代码回填事前记录。

输出为 `code-structure-comparison-1`，逐语言保存执行前、执行后与后减前。比较函数数、分布中位数/P90/最大值/均值和其他可比数量，不输出百分比、质量分、任务难度、人工时间或成本收益。分位数之差不是函数改变量的分位数；没有逐函数关联，不称配对函数比较。新增、删除、拆分函数都会改变分布，变化正负不标成好坏。

版本不同、要求改变、部分覆盖、未知范围或语言缺失时分别查看原报告并列出阻断原因，不把缺失语言或空分布补零，不挑可比较部分冒充整个范围。

## 可直接程序调用的命令

```powershell
# 默认关闭，不读取before/after，也不建立用户身份或上传
npm run contribute -- compare-code-reports --out .local/code-comparison-disabled.json

# 用户确认范围后，显式比较；每次使用新的输出文件
npm run contribute -- compare-code-reports --before before.json --after after.json --same-scope-confirmed --enabled --out .local/code-comparison-001.json

# JS/TS数值报告的机器Schema
npm run contribute -- schema --format code-set-report --out .local/code-set-schema.json
```

下载工具包包含同一个比较程序与Schema，不依赖模型。JSON Schema表达字段结构；数量守恒、分布关系和比较资格由配套程序执行，不能只用外部JSON Schema校验声称通过全部业务规则。

## 验证与未覆盖部分

用独立临时目录的固定源码生成报告，检查原JS/TS数值、Python方法、重复与缺项、空函数、解析版本、语言切换、修订与阶段、错误不回显以及CLI新文件保护。界面使用同一共享组件，静态渲染检查支持表格含义与默认关闭；实际浏览器交互和新机器安装状态另见 `status.md`，不把组件静态检查称为GUI验收。

已接入M-04的 [补丁计量](patch-measurement.md)，分别保留增删条目、修改块、分散程度、声明与内容未知。原报告不直接进入任务上传协议；已新增[可选白名单观察](code-observations-upload.md)，用户选择后经capture生成本人上传字段。尚未自动绑定每日摘要，也不提供逐函数匹配、任务评分或经验难度校准。这些后续接入仍独立推进。

# 固定选型后的观测组重采样

日期：2026-10-15。方法版本 `group-resampling-1`，公开报告 `ranking-source-holdout-public-2`，榜单契约 `boards-12`。对应 S-05、S-06、R-05 的第一阶段；不表示完成时间块、任务族依赖、选择稳定性或经过覆盖率校准的区间估计。方法依据及采用边界见文末原始来源。

## 回答的问题与解释范围

这项分析回答：在当前已观察的来源关联组中，如果整组重新赋予抽样次数，已经固定的模型与 Harness 的单位验收费用会怎样变化。原选择集先冻结配置，评价集再计算；重采样不重选模型、不重选 Harness、不修改任务权重，也不按完成率筛掉困难样本。

页面称为“观测组重采样范围”，不称已校准的 95% 置信区间，不给出未来获胜概率或未来费用保证。1000 次重复的经验分位数只是条件于本次数据和冻结选型的描述。即使组数达到发布门槛，未观察到的失败、高费用尾部、未知依赖和任务分布变化仍可能使范围失真。

现有历史排名仍采用全量数据按任务条件选择最低费用 Harness；独立评价面板保留选择侧原赢家及顺序。新增范围不改变名次，也不将历史全量赢家冒充独立评价通过的赢家。

## 逐组数值矩阵

与基础留出评价共用持有人和可信来源关系的完整连通组；可信私人中间关系也参与连接。没有证明的自报来源不用于合并陌生身份。组不等于独立真人，协议中的可单独验收根目标也不表示其统计独立。

在同一读取事务中，对冻结的每个模型、每个条件及完整 Harness 配置，查询评价侧各组的：

| 数值 | 含义                                                   |
| ---- | ------------------------------------------------------ |
| N    | 已结束根目标数；包含已结束失败，排除仍在进行的目标     |
| A    | 通过相应验收规则的目标数                               |
| C    | 全部相应归属支出，含失败、重试及已按费用协议核对的费用 |

读取只使用派生数值事实，不解析提示词、任务正文或代码。逐条件核对组矩阵的 N、A、C 和组数，必须与基础聚合完全相等。缺读、重复映射、数值溢出或金额不一致报错，不补零继续计算。某组在某条件没有事实，只有在完整矩阵通过核对后，才作为该条件中没有观测处理。

## 抽样与费用公式

设评价侧共有 G 个已知关联组，每次有放回抽 G 次，得到各组次数 K_g。所有模型和条件共用这一组 K_g，保留跨模型、跨条件的已知关系。组内目标不再单独抽样。

```text
N_s* = sum_g K_g N_gs
A_s* = sum_g K_g A_gs
C_s* = sum_g K_g C_gs

U* = sum_s q_s C_s*/N_s*
V* = sum_s q_s A_s*/N_s*
R* = U*/V*
```

q_s 为原固定任务构成。这里先汇总费用和验收再取比值，不平均每个组的单位验收费用，也不删除零验收条件重新分配权重。根目标数不是对话轮数、请求数或 Token 数；同一目标的失败尝试仍留在费用中。

每次重复必归入四类之一，1000 次全部保留：

| 类别         | 条件                   | 分位数处理                   |
| ------------ | ---------------------- | ---------------------------- |
| 有限         | 所有条件 N>0 且 V>0    | 保留 R                       |
| 零验收有支出 | 所有条件 N>0，V=0，U>0 | 正无穷；允许没有有限上界     |
| 0/0 未定义   | 所有条件 N>0，V=0，U=0 | 未知非负范围，不认作免费完成 |
| 缺条件       | 任一必需条件 N=0       | 未知非负范围，不缩小比较对象 |

采用经验逆分布函数，不在有限值与无穷之间插值。1000 次时取从 1 起数的第 25 与第 975 个位置。为包住未知结果，下界计算把未知当 0，上界计算把未知当正无穷；零验收有支出在两端都作为正无穷。结果端点用 `finite/value` 或 `unbounded` 表示，不把 JSON 的 `null` 冒充数值无穷。

## 发布条件和退化观测

原基础评价仍逐配置要求至少20个结束目标、5个关联组、最大组任务占比不超过35%。模型任一必需条件不完整时，选择侧费用、评价分项和所有重采样数值一并隐藏，避免与全量结果相减反推。

附加分布还要求每条件至少20个已知关联组。这是本项目版本化的工程发布规则，论文没有证明“20组就足够可靠”。每条件中，至少有一个验收的组，以及尚未全部验收的组，分别重新检查20个目标、5个组和35%任务占比；类别为空时保留边界诊断。未通过时隐藏重复分类数量和范围，不披露一个已读取前缀。

观测全部验收、全部零验收，或1000个有限重复值完全相同时，报告为退化观测，不显示 `[相同数值,相同数值]` 范围。全部验收不证明未来不会失败；全部零验收不产生有限单位费用。退化标记不是对总体方差为零的判断。

这些规则限制公开数值的支持范围，不是差分隐私保证，也不能证明任何数值摘要绝无重识别风险。公开结果不含持有人、来源、内部组标识、组矩阵、抽样次数向量、逐次值或原随机种子。

## 复现、历史和资源

种子由算法标识、费用/证据范围、月份和完整事实版本的规范化内容计算 SHA-256；随机 studyId、准备时间或重复点击不会换一条随机流。组按内部标识稳定排序，采用 Blackman 与 Vigna 的 xoshiro128** 1.1 状态更新，组下标用拒绝抽样消除取模偏差。公开仅保存种子摘要、方法版本、预定次数和解释标识。修改输入后必须使用新的事实版本；这不是对管理员直接改写派生事实的认证。

计算保持离线显式批处理，默认不配置活动评价集合，不新增定时轮询、模型调用或自动上传。沿用独立进程30秒、V8堆256 MiB、SQLite原生分配128 MiB和缓存8 MiB限制；它们不是整个进程 RSS 的硬上限。

附加矩阵最多20000组、8192条件槽、100000组条件记录，数值记录 JSON 累计最多16 MiB。重采样最多4000万逻辑工作单位，预检并在运行中计数；工作单位计组抽取、数值数组重置、已访问矩阵项和模型条件，不是 CPU 指令或 RSS 精确测量。采集或运算超限时丢弃整份附加分布，保留已完整核对的基础点估计并标记容量不足。不使用部分矩阵或先完成的重复。非容量异常、快照丢失仍使评价失败。

新报告使用公开格式2。格式1保留原格式和摘要，不自动补写范围；当前接口仍要求目标和事实版本严格匹配。永久历史登记不允许同一 `(targetId,dataVersion)` 更换结果，不能用重跑寻找满意范围。API、首页、比较页和导出共用报告；桌面私人反馈尚未消费这套留出结果。

## 已执行的数值实验

命令只生成隔离数值总体，不读用户数据库、不请求网络、不调用模型；输出不可覆盖：

```powershell
node --import tsx scripts/validate-ranking-resampling.ts <新的输出.json>
```

固定六种情景，每种2000个数据集，每个数据集1000次生产方法重采样，总计12000个数据集、1200万次重复。报告包含全部状态、零分母和缺条件数量、原始范围真值命中率、公开范围产生比例、产生后的条件命中率及 Monte Carlo 标准误。没有范围的运行仍计入总运行数和状态，不因不利结果删除。零产生时条件命中率为未知，不能说成0%或100%。

| 隔离情景                                   | 原始范围包含解析真值 | 公开范围产生数 / 2000 | 解释                                                                    |
| ------------------------------------------ | -------------------: | --------------------: | ----------------------------------------------------------------------- |
| 5组，每组95%概率全部成功                   |               21.90% |                     0 | 少组不能提供可靠范围                                                    |
| 同一总体20组                               |               64.65% |                     5 | 705次全验收退化、1290次支持不足；仅5次产生范围，条件命中3/5，不据此推广 |
| 50组，组规模/费用/验收相关，两条件固定权重 |               94.05% |                  2000 | 仅说明该预设总体，不能认证所有任务的95%覆盖                             |
| 表面50组，实际每10组共享冲击               |               67.80% |                  1689 | 未识别依赖会使范围过窄；311次退化仍保留                                 |
| 50组，1%概率出现高费用低验收组             |               38.55% |                   774 | 1226次样本未见尾部而退化；只看774次的条件命中率会掩盖问题               |

原始范围包括内部退化值，不能直接向用户作为置信区间发布。表中“命中”不是已验证的名义覆盖率，情景也不是全部实际环境。全验收的解析反例为：真实单位费用 `1/0.95`，5组全部成功的概率 `0.95^5≈77.38%`，这些数据却只能重采样得到 `[1,1]`。本次实验约20.6秒，结束时进程 RSS 约93.4 MiB；这不是生产性能或峰值内存承诺。

## 研究依据与后续范围

- [Cameron 与 Miller，2015，A Practitioner’s Guide to Cluster-Robust Inference](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf)：借鉴以组为单位保留依赖及少组问题；不将其回归模型下的 wild bootstrap 或 percentile-t 结论移植为本比值的精度。
- [Franz，2007，Ratios: A short guide to confidence limits and proper use](https://arxiv.org/html/0710.2024v1)：比值分母接近零时存在特殊问题，不能机械删除无穷结果或套普通有限区间。后续考虑 Fieller 和联合协方差方法，但当前固定条件加权比值不是直接对两个简单样本均值套公式。
- [von Luxburg 与 Franz，A geometric approach to confidence sets for ratios](https://arxiv.org/abs/0711.0198)：比值置信集合可能无界或不连通。当前只输出描述性经验范围，不称已实现该推断方法。
- [rliable 作者项目](https://agarwl.github.io/rliable/)：采用报告不确定性和可复现过程的方向；不将强化学习独立运行、IQM 或获胜概率直接当作本项目用户任务的适用方法。
- [Blackman 与 Vigna，xoshiro128** 官方源文件](https://prng.di.unimi.it/xoshiro128starstar.c)：核对状态更新、非全零初始化；参考实现允许公共领域使用。随机流用于可复现数值计算，不用于安全密钥。

固定选型后的逐组删除敏感性和集中度档位已另行实现，详见 [来源影响](ranking-source-sensitivity.md)，不改变本页重采样算法和实验结果。下一阶段分别处理选择侧重新选型的稳定性、真实时间留出、任务族和账期块依赖，并按需要用预设总体检查推断方法。评价侧重新挑最便宜配置后再计算稳定性会破坏独立评价，不能作为上述工作的替代。难度分级和自动采集、生成、上传、登录启动保持默认关闭。

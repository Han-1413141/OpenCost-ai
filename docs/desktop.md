# OpenCost 工作日记

桌面应用在本地连接 Harness，生成每日工作摘要，提供思维导图、自由画布、每日回顾和个人反馈。

## 启动与绑定

需要 Node.js 24，在公开仓库执行：

```sh
npm ci
npm run desktop:build
npm run desktop:start
```

首次启动后，在应用中复制绑定提示词，发送到常用 Harness。绑定码 15 分钟有效、仅使用一次。可以绑定多个 Harness，也可手动选择来源目录。来源路径保存在本机。

## 每日提醒

默认每天本机时间 17:30 提醒，时间可在设置中修改。应用在右下角请求许可，允许后读取所选日志并调用 Harness。自动生成、自动上传和登录时启动默认关闭，分别授权。

关闭主窗口后留在托盘；从托盘退出停止后台任务。电脑休眠不会被唤醒，恢复后只提示当日。没有新记录时跳过生成。

## 摘要与上传

原始片段先在本地脱敏，再交给所选 Harness 整理。现成结构字段直接复用；AI 整理按所选模型的用量计费。上传前可查看并编辑摘要、选择站点和分享范围。

摘要记录任务类型、完成量、状态、Token、轮次和费用。进行中的任务与已经结束但未完成的任务分别保存，当前难度分级关闭。

网站上传账号通过访问凭证连接。GitHub 登录用户可下载账号凭证导入应用；旧凭证继续访问对应的原记录。

## 日记与个人反馈

按天查看工作分支，使用思维导图或自由画布切换展示。上传后的个人反馈覆盖工作量、费用、Token、额度、完成情况和可比方案。连续记录一周或一个月后，可观察更稳定的趋势。

## 备份与退出

设置中可导出完整本地日记备份，保留历史修订和反馈。备份在本机生成。取消对话框即可放弃导出；已经开始的写入先完成再退出。

退出时停止提醒与新任务，取消正在等待的操作，并保存已取得的上传回执。网络中断时保留原摘要；再次上传复用原摘要编号，避免重复保存。

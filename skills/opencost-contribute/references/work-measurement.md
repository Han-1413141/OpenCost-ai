# 工作量与任务组成

当已有成果身份、内容修订或任务组成记录时读取本文件。普通会话摘要没有这些事实就保持 null，不要求 AI 重建原计划，也不额外读取未授权历史。机器协议通过 CLI schema 生成；以下说明决定计数边界。

## 四种数量分开

独立目标有自己的交付要求与验收边界，跨日、重试、换模型保持 UUID。组成部分是目标内的步骤或子成果，不能再计为根目标。成果量按 `kind + workType + unit` 分开，章节、图表、记录、字符和秒数不能混加。执行消耗包含所有尝试、失败、返工、后代代理、工具及资源，不能只留最后成功一次。

输入材料可以由多个独立目标复用。执行事件、费用与最终成果不能重复记账；共享开销按已有分配依据处理，不能给每个目标各记一次全部费用。

## 本地成果账本 workItems

每个事实保留 `id、taskId、artifactId、revision、derivativeOf、scope、isFinal、planVersion`，以及 completedWork 的类型、单位、计划、完成、验收、来源和覆盖字段。

- id 表示同一事实，重复副本沿用它；同 ID 内容冲突停止编译。
- artifactId 表示内容身份，不用文件路径或文件数代替。revision 是原成果的内容版本，不是导出软件的版本号。
- derivativeOf 只表示同内容的格式或尺寸衍生物。衍生物须指回本地已登记原成果；它不充当权威最终数量。对应内容版本与数量矛盾时停止编译。
- direct 表示不与其他事实重叠的实际成果；父级总量、容器汇总为 aggregate，只供核对，不再次相加。
- isFinal=false 的草稿、候选和废弃版本不进入最终量；同内容多个最终修订只取最新原成果内容版本。旧事实继续留在本地。
- planned 有值时 planVersion 必须指向本地原计划或已同意的变更。不能根据产出改写计划，completed 可以与 planned 不同。
- coverage.workItems 单独声明 complete/partial/unknown；它不等同代理、日志或费用范围完整。缺完整覆盖时总量为 null，保留已观察小计。

例子：同一页面输出 PPT、PDF、PNG 是一页成果；同一视频输出两种分辨率不增加内容秒数；1,000 条记录经过三道清洗仍是 1,000 条不同记录；重复执行同一测试仍是一个测试场景。合法的相同源文段落有自己的来源范围，不能仅凭文本哈希删除。

## 本地组成图 workGraphs

每个根目标最多一份合并后的图。字段由 schema 生成，包括 taskId、basis、coverage、integrationRequired、integrationAccepted、nodes、edges 和 sharedStates。

nodes 的本地身份、父节点、类别、角色、必需性、完成及验收结果来自已有计划或记录。容器只组织层级，不作为原子部分重复计数。required=null 表示没有必需性依据，不能擅自变成必需或可选。已验收部分必须已完成。

edges 分别记录 dependency 和 feedback，连接不同的原子部分。重复同一边先去重，拒绝不存在的节点和自环。组成层级中的父子循环属于错误；真实工作的反馈循环保留，不能删成独立任务。

sharedStates 按稳定共享对象分组，成员身份只在本地。100 个部分共用一个状态记一个共享组，不扩展成 4,950 条两两关系。

程序生成 `evaluation.workStructure`：原子部分总量、必需量、完成与验收量、依赖边、最长依赖深度、共享状态组、反馈链接与循环组、整合要求及结果。深度只在计算时缩合互相依赖的部分，按组间最长路径的边数计算；它不等于代理层级，不是难度得分。局部图只保留观察小计，不声明完整类型。

共同交付目标的必需部分全部通过，且要求整合时整体整合通过，才报告根目标通过。可选部分未做不阻止根目标验收。局部成果可完成、可验收，整合失败时根目标仍未通过。不能按总体完成比例猜各类成果数量。

## 输出、历史与证据

只上传汇总后的 completedWork、workStructure 和 executionScope。原图、成果身份、修订关系、计划映射及来源清单留在本地 capture/manifest；不能上传本地 packet。

保留原捕获文件、所有版本、生成时的价格与反馈，不覆盖旧结果。当前难度框架是 `domain-difficulty-draft-2`，只读规范与本地评审结构，不属于生产上传字段；不得填写未来难度标签或执行草案评分。

这些校验检查一致性、去重和费用守恒。哈希不能证明最初数量真实，模型声称“专家级”或“已经核验”不能形成独立证据。费用和验收仍按已登记验证方与对应来源判定，日记的对话声明仍是 local_unverified。
